# 08 故障排查

## 编辑器要求先初始化

进入“设置 → Asset Track”，选择 Vault 文件夹并点击“使用并初始化”。数据库固定
为 `<根目录>/data/accounting_system.db`。

## 当前运行时不支持 node:sqlite

这表示 Obsidian 应用可能已更新，但底层桌面安装器仍然较旧。请从 Obsidian 官网
下载并覆盖安装最新桌面安装器，再重启 Obsidian。插件在能力检查失败时不会创建或
修改数据库。

最低应用版本为 1.9.10；设置页“重新打开数据库连接”可在升级后重新探测。

## 数据库无法打开

- 若测试库来自旧版本，先使用开发说明中的离线工具生成新数据库副本。
- 不要在两台同步设备上同时写同一个 SQLite。
- 关闭另一台 Obsidian 或其他 SQLite 工具后，重新打开数据库连接。
- 复制诊断信息；诊断不包含金额、商品或借款对方。

## revision 冲突

数据库已被另一编辑会话修改。当前草稿不会静默覆盖新数据；重新加载 canonical
rows 后再编辑。

## 备份恢复失败

- 设置页支持 AssetTrack ZIP 或 SQLite 数据库文件。
- 候选必须通过文件 hash、CSV 字段与行数、内容摘要、schema 和
  `integrity_check`。
- 校验失败不会关闭或替换当前数据库。
- 正式替换前会创建安全快照；失败会回滚原数据库。

## 账单重复流水

增量导入会追加本次全部有效记录，不执行去重。保存前在逐项视图删除不需要的行，
或放弃并重载。
