# Release v1.2.0

Asset Track 是一个 macOS 桌面版 Obsidian 本地财务插件。数据保存在你选择的
Vault 文件夹中，SQLite 是唯一事实源，不需要安装 Python、Node 或其他运行环境。

## 安装

下载发行附件：

```text
AssetTrack-1.2.0-macos-arm64.zip
```

注意：不能只把 ZIP 文件本身放进 `.obsidian/plugins/`。需要先解压，最终目录
必须是：

```text
<你的 Vault>/.obsidian/plugins/asset-track/
├── main.js
├── manifest.json
├── styles.css
├── versions.json
└── sidecar/
    ├── AssetTrackSidecar
    └── _internal/...
```

在 macOS 终端中，可以这样安装：

```bash
VAULT="/path/to/your/obsidian-vault"
unzip -q AssetTrack-1.2.0-macos-arm64.zip \
  -d "$VAULT/.obsidian/plugins"
```

解压完成后，在 Obsidian 中打开“设置 → 社区插件”，关闭受限模式（如果系统
提示），启用 **Asset Track**。升级已有版本前请先退出 Obsidian，再替换整个
`asset-track` 目录；如需保留插件设置，请保留目录中的 `data.json`。

本版本发行包是 Apple Silicon（arm64）构建。Intel Mac 不能使用此附件；当前
sidecar 使用本地 ad-hoc 签名，macOS 首次运行若出现安全提示，请通过系统允许
后再启用插件。

## 首次使用：选择目录并初始化

安装并启用插件后，必须先完成初始化：

1. 打开“设置 → Asset Track”。
2. 在“Asset_Track 根目录”中选择 Vault 内的一个数据目录，也可以使用推荐的
   `Asset_Track` 新目录。
3. 点击“使用并初始化”。
4. 初始化完成后再打开 Ribbon 或“打开编辑器”。

数据库固定位于：

```text
<你选择的 Asset_Track 根目录>/data/accounting_system.db
```

插件不会把数据库放进 `.obsidian/plugins/`，也不会在未初始化时自动创建数据库。
切换数据目录前，请先处理未保存草稿并完成手动备份。

## 日常使用

- “分析”：查看 Home、年度和月度图表。
- “流水”：编辑现金、理财、支出、收入、代付、加仓、提现和固定资产。
- “借款”：维护借款发生日期、金额、还清状态和还清日期。
- “规则”：维护分类定义和商品匹配规则。

保存月份前，插件会执行流水质检；有错误时不会写入数据库。导入和规则预览
也只会修改当前草稿，确认无误后仍需点击“保存月份”。

## 导入流水 CSV

在月份编辑器顶部点击“导入 CSV”。格式有两层要求：

### 1. 表头要求

必填 3 列：

| 表头 | 要求 |
| --- | --- |
| `商品` | 流水说明，不能为空 |
| `收支` | 只能填写 `支出`、`收入`、`代付`、`加仓`、`提现` |
| `金额` | 数字；允许千分位逗号和 `¥`，导入时按绝对值读取 |

可选 2 列：

| 表头 | 作用 |
| --- | --- |
| `日期` | 建议使用 `YYYY-MM-DD`；缺少时预览默认使用当前月份 1 日 |
| `分类` | 按现有分类名称精确匹配；匹配不到时保存前质检会提示 |

因此 CSV 可以是 3 列、4 列或 5 列，不是固定四列。四列格式可以是：

```csv
商品,收支,金额,日期
午餐,支出,35.5,2026-07-02
工资,收入,"10,000",2026-07-01
```

完整五列格式示例：

```csv
商品,收支,金额,日期,分类
午餐,支出,35.5,2026-07-02,餐饮基础
工资,收入,"10,000",2026-07-01,工资收入
```

### 2. 导入操作要求

1. 选择 CSV 后确认导入行数和类型汇总。
2. 选择“追加”或“替换”。
3. 检查日期、商品、金额和分类。
4. 点击“保存月份”，导入内容才会写入 SQLite。

没有 `日期` 和 `分类` 时，相同 `商品 + 收支` 的行会先合并；提供任一可选列时，
则保留原始行。备份生成的 `transactions_backup.csv` 是完整备份材料，不能直接
当作这个导入入口的简化流水 CSV。

## 备份

插件不自动备份。重要修改前，请从“设置 → Asset Track”执行手动备份；恢复前会
验证 manifest、hash、schema、行数和 SQLite 完整性，验证失败不会覆盖当前数据库。

## 已知限制

- 仅支持 macOS 桌面版 Obsidian。
- 本发行附件仅支持 Apple Silicon（arm64）。
- 当前版本依赖完整 sidecar 目录，不能通过标准 Community Plugins 安装器安装。
- 不提供云同步、银行同步、移动端写入或自动备份。
