## 变更范围

- 下方工具栏采用视图、分类、编辑三组。分类包含规则分类、AI 分类、修改分类；编辑包含编辑信息、编辑标签、撤回。
- 宽窗口同行，窄窗口按分组换行。信息与标签编辑使用一致窗口样式，确认后进入当前草稿。
- 信息编辑支持商品与交易对手独立填写，留空保留，显式勾选清空。复用现有两种字段操作，在全部准备成功后一次更新草稿，并只记录一步撤回。
- 标签窗口切换添加与移除，保留逐项表和汇总展开明细的每行标签编辑按钮。
- 全选置于表头，和行号排序／汇总类型排序分别使用勾选框与按钮。两个独立点击区域，支持半选。
- 逐项表全选当前类型表，汇总表全选当前汇总视图成员，数量按逐笔流水计算。切换视图保留选择。
- 规则分类有选择时处理选中项，无选择时处理本月全部可匹配流水。撤回与当前选择独立，悬停显示最近操作。
- 移除行号下的导入／手工来源标记。代付规则及数据健康按用户决策继续保留。
