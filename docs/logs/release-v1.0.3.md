# Release v1.0.3

日期：2026-07-29

## 按钮交互

- 普通按钮 hover 使用强调色边框和外环、更深阴影、上浮 2px 与轻微放大，避免
  仅依赖不明显的主题背景变化。
- 主操作和选中按钮 hover 保持强调色，增加亮度及强调色阴影；危险按钮使用红色
  背景、边框和外环。
- 所有可点击按钮强制显示手型指针，避免被 Obsidian 主题覆盖；禁用按钮显示禁用
  指针。
- 按下按钮时回落并轻微缩小，键盘聚焦时显示两像素焦点轮廓。
- 尊重 `prefers-reduced-motion`：取消过渡与 hover 位移，不影响颜色和焦点反馈。

## 兼容与验证

- 不改变数据库、schema 9、Service、Repository、备份格式或财务口径。
- 自动验证结果在正式构建完成后记录；三平台真实 Obsidian smoke 仍按社区发布
  规划单独执行。
