## 授权与范围

用户已确认 HTML 交互方案，授权接入插件、写入个人库、完整退出并重启 Obsidian 验收。2026-10-24 用户确认测试可以，先要求审阅发布说明，随后确认“可以，测试通过后发布吧”，授权提交、推送与公开发布。测试结束后须退出 Obsidian。个人账本仅检查显示、打开与关闭，不提交真实迁移、删除、恢复或批量改写。

## 变更

- 共用弹窗的未提交输入保护、处理状态与固定动作区；普通／危险确认分开。
- 精简合并结果，不再逐组展示原始明细；入口改为合并此组。
- 批量字段与多标签添加／移除同窗预览，移除替换标签入口；保留旧审计兼容。
- 流水草稿最多十步撤回，恢复流水、选择／保护范围与待提交审计；保存、重载、外部数据变化和普通手工编辑使撤回链失效。
- 分类表提供属性、迁移、更多入口，重分配列宽；属性编辑与历史迁移拆开。
- 分类转移并删除：保护备份、revision 和引用校验，同事务转移流水与规则、移除定义并记审计。
- 标签关联转移去重；整个属性名称移除只清除关联，不跨属性覆盖。
- 历史商品按名称／分类／规则分任务；成功后留窗，切换时保护输入。
- hover 显示／消失 200ms，统一升级提示、加载失败反馈。

### 本轮验证边界

- 分类实际转移／删除、历史改名／分类写入、多标签持久化、草稿撤回及合并保存均用隔离合成数据库或组件测试验证，个人库没有执行正式写入；这不等同于这些成功路径已经完成宿主鼠标验收。
- 本轮真实宿主没有覆盖窄面板、浅色主题、英文、故障注入重试、AI 联网及旧库升级／恢复；不标记为通过。HTML 审查稿和自动化检查不能代替这些宿主场景。
- 没有保存私人账单截图或 AX 内容到仓库。用户数据路径和安装前备份位置只留在本地安装报告中。
- 以上为代理自行执行的验证范围；用户随后独立测试并确认可以，不推断其具体环境或操作范围。后续持续回归按 [界面回归协议](../16-ui-regression-protocol.md) 执行，每次测试结束均须退出 Obsidian。
