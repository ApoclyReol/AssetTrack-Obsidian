# v2.3.5 发布与验收记录

日期为 2026-11-03。本次相对正式版 v2.2.0 汇总本地 v2.3.0～v2.3.5 迭代。
用户已完成个人库测试，并明确授权发布。完整中英文发布说明由根目录 CHANGELOG 提取。

## 更新范围

- 月份自主选择，允许跳月及补充历史月，滚动分析采用最近十二个有数据月份。
- 统一创建规则窗口，匹配条件与处理结果左右分栏，金额和重写直接展示，冲突用简短提示指出已有规则。
- 规则应用以当前草稿为准，有选择时处理选中项，无选择时处理本月可匹配流水。
- 流水工具栏分为视图、分类、编辑三组。信息编辑集中商品与交易对手，标签编辑集中添加与移除，保留行内标签按钮。
- 信息双字段操作全部准备成功后统一进入草稿，并作为一步撤回。复用既有预览和审计，保存时校验 revision 与 before／after。
- 全选、选择数量与取消选择同行，表头专注排序，支持半选与汇总成员选择。取消选择预留占位，避免尺寸跳变。
- 单组合并仅保留“保留带标签项”，取消后带标签项参与合并并去除结果标签，不同分类分别处理。
- 分类、属性定义和标签定义同页维护。直接展示删除分类，为分类说明增加空间。
- 年／月三维分析共用展示，分类按钮显示金额和比例并打开相关流水，精简年度面板并重排储蓄率、历史趋势与固定资产。
- 修复空悬浮提示、帮助图标对齐、汇总金额符号、取消路径、来源标记及理财空工具栏。
