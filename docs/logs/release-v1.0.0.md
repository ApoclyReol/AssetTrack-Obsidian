# Release v1.0.0

日期：2026-07-28

## 发布信息

- 插件版本：`1.0.0`
- 最低 Obsidian：`1.9.10`
- 桌面版：macOS、Windows、Linux
- 数据库：SQLite schema 9
- 安装目录只包含 `main.js`、`manifest.json`、`styles.css`
- 手动安装包：`AssetTrack-1.0.0.zip`，解压后得到完整 `asset-track/` 目录
- 不要求用户安装 Python、Node、虚拟环境或平台架构包

## 用户体验

- 五类流水分别显示块内行号，质检提示使用相同编号。
- 新建支出或收入的分类初始为“请选择”，不默认使用第一个分类。
- 流水表完整展开，不再限制表内最大高度；页面滚动承担浏览。
- 导入入口统一为“导入账单”，支持 CSV、XLSX 和 XLS，并提示用户先整理真实
  账单的列名、范围和无关记录。
- 交易状态选项来自当前文件实际内容，用户必须主动选择允许导入的状态。
- 设置页只说明 ZIP 备份与 ZIP/SQLite 恢复，不展示内部 schema 或备份格式号。

## 数据与规则

- 新数据库为 schema 9；`transactions` 和 `auto_rules` 增加
  `counterparty TEXT NOT NULL DEFAULT ''`。
- 流水同时保存交易对方和商品；规则至少填写其中一项，两项都填写时必须同时
  命中，并优先使用字段更多的精确规则。
- 插件不自动迁移 schema 8。私有数据通过一次性离线工具生成 schema 9 新副本，
  并校验完整性、外键、行数和源文件未变；过渡完成后不在仓库保留该工具。

## 分析

- 月度理财状态新增与严格上一个自然月总持仓的金额和百分比比较。
- “分类与上月对比”排除标记为大额的分类，避免与下方大额支出重复。
- “分类与上月对比”收敛为一张横向图：分类旁直接显示增减额，每根柱右侧直接
  标记上月或本月金额，不再使用图外增减标签和难读的数值横轴。
- 分类异常变化仅在绝对变化达到 `max(100 元, 历史基准 × 30%)` 时展示；周期项
  缺失仍独立检查，大额分类不重复进入变化列表。
- “异常与变化”按分类合并上月和近三月口径，只显示“分类、金额、异常情况”；
  大额支出改为较窄的“商品、金额”中文两列表。
- 异常表改为固定列宽、内容居中和长文本自动换行，避免横向滚动条。
- 月度对账移到顶部资产环比之后，只显示对账差额及“多消费少支出、少消费多支出、
  平账”状态；差额绝对值小于 100 元统一标记为平账。

## 导入设计

收支值映射继续是强制步骤。不同来源的付款、收入、转入和转出文字必须先映射为
AssetTrack 的五类统一资金语义，之后才能生成预览。该设计用于阻止不同平台字段
含义直接污染财务计算，而不是增加导入步骤。

## 测试重点

- 块内行号、新建空分类、完整展开和质检定位。
- CSV、XLSX、XLS 第一工作表解析、交易对方和动态状态过滤。
- 交易对方/商品规则的精确优先级与 revision。
- schema 9 新建、schema 8 离线副本迁移、源库不变和备份恢复。
- 理财环比、大额分类排除和异常双阈值。
- TypeScript 类型检查、27 项插件测试、生产构建、三文件结构和 `node:sqlite`
  冒烟。

## 首个正式版本与开发目录收敛

- 旧私有数据已通过一次性离线流程生成 schema 9 副本，并完成完整性、
  外键、字段和业务表行数核验；正式插件未加入自动迁移逻辑。
- 完成私有数据过渡后，仓库删除一次性迁移工具及其测试，不长期维护
  双 schema 开发路径。
- 清理被忽略但仍留在工作树中的 Python 字节码、旧 Python 测试、虚拟环境、
  `.var`、旧 sidecar/PyInstaller 构建、历史 ZIP 和本地数据库副本。
- 当前长期源码边界只包括 TypeScript 插件源码、插件测试、构建安装脚本和编号
  文档；可安装产物仍只有 `main.js`、`manifest.json`、`styles.css`。
