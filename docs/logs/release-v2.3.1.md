# v2.3.1 本地界面修正

日期为 2026-11-03。用户授权根据代码修正并直接安装个人库，本轮由用户稍后验收。

## 变更

- 创建／编辑匹配规则窗口固定尺寸并适应视口，金额与重写始终展示，内部滚动，操作按钮保持可见。
- 冲突按已有规则显示商品、交易对手、金额条件和分类，说明重复、分类不一致、金额交集或重写跨分类的处理方向。
- 创建月份取消直接退出。流水正常状态标签与空状态占位移除，错误、进度及操作结果继续展示。
- 分类表、属性与标签定义放在同页，后两者左右分栏。删除入口直接展示，分类说明获得更多宽度。
- 年／月共用标签、属性和分类展示，类别名称完整换行。独立年度属性明细面板暂时收起，储蓄率、全历史趋势和固定资产顺序调整。
- 年度维度明细加载其相关月份；属性维度补充既有笔数信息。
- 空说明不创建悬浮提示，修正合并空白浮层；对账差额帮助图标同行居中。
