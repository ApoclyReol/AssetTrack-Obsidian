# v2.3.0 本地更新与验收记录

日期为 2026-11-03。本轮由用户授权实施、安装到主库并重启验证，界面 HTML 已获用户确认。

## 变更范围

- 当前草稿直接应用规则，取消手工修改保护与额外覆盖确认。连续应用使用前一次操作结果作为保存审计基准。
- 规则创建左右分栏，金额与重写按需展开，冲突规则编号与条件就近展示，可在同窗编辑已有规则。
- 选月创建、跳月与补历史月。分类、属性和标签统一在分类设计中维护。
- 汇总金额显示正数，移除流水原始行入口，整理分类与编辑按钮分组。
- 合并取消结果预览，默认保留带标签项，取消后参与合并并清除结果标签。
- 属性统计可选择自定义属性，取最近 12 个有数据月份。年／月维度按标签、属性、分类排列，年度分类完整列表可换行。
- 统一帮助图标与勾选控件对齐。Release 创建和更新显式设置版本标题。

## 数据边界

schema 13 / 备份格式 12。主库用于显示、交互与取消验证，数据写入验证使用合成 fixture。
自动合并为后续候选，个人标签由用户自行维护。

类型检查与 lint 通过。48 个测试文件、422 个测试通过，包含本轮新增的选月、自定义属性跨年窗口、冲突规则编辑和连续规则应用回归。
独立性能验证通过，覆盖 5 万笔合成流水。生产构建、三文件发布检查和 `node:sqlite` 冒烟通过。

## Obsidian 宿主验证

测试依据为 `docs/16-ui-regression-protocol.md`，测试日期为 2026-11-03，执行者为本轮 Codex。
环境为 macOS、Obsidian 1.15.0、中文、当前浅色主题，插件为本地 v2.3.0。
实际主库完成全宽显示及 920 CSS 像素视口检查。主库财务内容仅用于显示和可放弃的草稿操作，持久化结果由隔离合成 fixture 验证。

## 收尾校验

- 最终构建已完整退出并重启载入，再次点击出账／入账／理财，确认分类与编辑分组正常，理财页省略空组。
- 再次验证新建规则冲突编号、进入已有规则后标题同步及放弃修改路径。
- 安装前已备份旧插件、设置和一致性账本快照。测试前后主库全部业务表逐表数据摘要相同，完整性检查通过，数据目录核对一致。
- 最终安装文件逐项与构建文件 SHA-256 相同。交付文件扫描通过。
- 已关闭开发者工具、恢复正常视口，完整退出 Obsidian，应用清单确认 `isRunning=false`。
