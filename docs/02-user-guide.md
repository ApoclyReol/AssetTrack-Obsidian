# 02 用户指南

> 文档角色：用户阅读。本文只说明你为什么使用 Asset Track、每月要做什么，以及遇到
> 问题时如何处理；技术实现请从[开发维护文档](00-reading-guide.md)进入。

## 先记住一件事

Asset Track 不要求你每天逐笔记账。它把账单整理放在每月集中完成：

```text
导入账单 → 处理少量异常 → 补充资产 → 完成对账 → 查看分析
```

你需要判断真正不确定的事情，系统负责重复的整理工作。

## 第一次使用

1. 在“设置 → 第三方插件 → 浏览”中搜索并安装 **Asset Track**。
2. 打开“设置 → Asset Track”。
3. 在当前 Vault 内选择一个专用数据目录。
4. 空目录点击“创建新数据库”；已有数据库点击“载入数据库”。
5. 从命令面板或功能区打开 Asset Track 编辑器。

1.7.0 要求 Obsidian 1.13.0 或更高版本。安装前请先升级到最新可用的 1.13.x 桌面版。

## 每月结算怎么做

### 1. 收集账单

从本月使用过的支付平台导出账单，尽量确认每份账单的来源和覆盖日期。若有多个理财账户，
同时准备好本月加仓或提现分别对应的账户。

### 2. 导入账单

在“记录 → 流水”子页面顶部点击“导入账单”，选择文件并确认字段。支持 CSV、XLSX 和 XLS。
流水按“出账（支出）/入账（收入、代付）/理财（加仓、提现）”分 Tab；出账和入账还可切换逐项、按商品汇总、按交易对手汇总。

### 3. 处理需要判断的问题

检查商品-分类冲突、空商品、日期或金额异常。稳定重复的商品分类可以交给规则；不确定的项目留给自己判断。

### 4. 补充月末状态

在“记录”主页面的第二层导航中，分别打开“资产账户”“借款”和“固定资产”，更新月底状态。
理财流水中的加仓和提现可以在“账户”列选择对应的理财账户，便于月度分析按账户查看。
上月未还的借款会自动出现在后续月份；在哪个月还清，就在那个月勾选“本月还清”。

### 5. 完成检查

各子页在页面顶部分别点击对应的“保存资产”“保存借款”或“保存固定资产”；流水导入和规则处理后
点击“保存流水”。保存当前区块不会改写其他区块。切换主 tab、记录/配置子页面、月份或创建月份时，
如果当前页面有未保存修改，系统会先提示保存或放弃。随后查看未处理问题和对账差额；差额是
排查线索，可能来自漏导账单、漏记收入、类型选择错误或资产状态未更新。

### 6. 查看结果

确认本月已经整理完成后，再到“分析”查看消费结构、资产变化、周期支出和长期趋势。

## 导入账单的最短路径

1. 选择账单文件；
2. 确认日期、商品、金额和收支对应的字段；
3. 查看接受、忽略和异常记录；
4. 应用到本月；
5. 点击“保存流水”。

系统会记住常用的字段、收支值和状态选择，下次导入时自动预填，但每次仍会保留预览
供你确认。

### 导入时需要知道的几件事

- 没有日期或日期为空时，记录会暂时使用所选月份的第一天；
- 无法识别的日期、金额或收支类型会被标为无效；
- 空商品、零金额和缺少分类通常会作为提醒保留，方便之后处理；
- 增量导入不会自动去重。重复导入同一份账单或重叠日期范围，可能产生重复流水；
- 覆盖当前月份只替换流水，不会替换现金、理财或固定资产；
- 原始账单不会被保存到插件设置中。

如果导入预览中的记录数量或日期范围不对，先不要应用，返回检查文件和字段选择。

确认账单字段映射后，新导入流水会继续生成当前规则的影响预览；确认规则结果后才进入
当前草稿，最后仍需保存流水。这样导入不会静默改写已有流水，来源文件也会随新流水保留。

## 分类、规则和冲突

规则用于减少重复分类，不会替你静默修改历史流水。配置下的“数据健康”会直接打开商品-分类冲突表，
不再通过多个问题框分流；点击具体商品后，可编辑商品名称或迁移历史分类。

- 稳定、重复的商品可以创建规则；
- 同一商品出现多个分类时，先查看冲突再处理；
- 批量统一商品或迁移分类前，系统会先显示影响范围；
- 确认后才会写入，取消不会改变已有记录；
- 不确定的流水可以暂时保留，优先处理真正影响本月结算的问题。

“配置 → 商品总览”适合查看商品或交易对手的长期金额、次数和月份变化，也可创建规则、编辑商品和编辑分类；
“配置 → 匹配规则”维护三种精确规则：仅商品、仅交易对手、交易对手 + 商品。固定优先级是
“交易对手 + 商品 ＞ 商品 ＞ 交易对手”，同一条流水只采用一条规则；规则修改不会自动回写历史。

选择流水后，可以先预览再应用规则；批量修改在同一个编辑窗口中显示简要前后对比，确认后直接进入当前草稿。
单笔流水可创建规则，收入和代付可以互相转换，代付也允许使用支出类分类并参与 AI 分类。确认只会把结果放入当前草稿，仍需点击“保存流水”；操作审计
仍保存在本地数据库，但不再在流水页提供单独的操作记录按钮。

## 分析怎么看

- **年度**：查看年末资产、长期趋势、周期消费和当年出现过的固定资产；
- **月度**：查看当月分类变化、异常和大额流水，并按理财账户查看本金、资金流、市值、流动资金、仓位和收益率；

“记录”用于编辑事实，“配置”用于维护分类、规则和历史冲突；分析只读取已经保存的数据。

收入和资产增长、支出和资产下降使用不同颜色表示。分析数字来自已经保存的月度数据，
不是独立维护的另一份账本。

## 备份与恢复

- 重要修改前，在设置中导出一份完整备份；
- 备份应放在 Vault 或仓库之外的安全位置；
- 恢复前系统会先检查备份，确认后才替换当前数据；
- 恢复或切换数据目录前会保留当前数据的保护快照；
- 禁用或卸载插件不会删除数据库和备份。

Asset Track 不执行定时云备份。是否备份、备份到哪里、何时恢复，都由你决定。

## 语言与隐私

界面会跟随当前 Obsidian 语言。中文环境显示中文，其他语言显示英文；账户、分类、
商品和流水说明等你创建的内容保持原文。

数据保存在你选择的 Vault 内目录中。插件不要求账户、不包含遥测。未配置 AI 时不联网；
如果主动启用 AI，只有选中的可分类流水和完成分类所需的分类定义会发送到你配置的 API，
API Key 只存放在 Obsidian SecretStorage，不写入设置、数据库、日志或请求正文，也不会枚举 Vault 中的其他文件。

## 遇到问题时

- **看不到数据**：检查是否选择了正确的数据目录，再重新载入数据库；
- **导入数量不对**：回到预览检查日期、状态和收支字段；
- **出现对账差额**：先检查账单是否完整，再检查资产、流水页中的借款区块、理财和特殊流水；
- **修改被拒绝**：先重新加载当前月份，确认没有其他窗口刚刚保存同一内容；
- **插件提示版本过低**：升级到最新可用的 Obsidian 1.13.x 桌面版。
