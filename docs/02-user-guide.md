# 02 用户指南

## 首次使用

1. 把完整 `asset-track/` 目录放入 Vault 的 `.obsidian/plugins/` 并启用。目录内
   只需 `main.js`、`manifest.json` 和 `styles.css`。
2. 打开“设置 → Asset Track”。
3. 在“Asset_Track 根目录”中输入关键词，从 Vault 文件夹联想列表选择已有目录；
   也可以使用推荐的 `Asset_Track` 新目录。
4. 点击“使用并初始化”。数据库固定创建或读取于
   `<根目录>/data/accounting_system.db`。
5. 完成前，Ribbon 和“打开编辑器”只会引导回设置，不会创建数据库。

## 日常使用

- “分析”：Home、年度、月度实时图表。
- “流水”：现金、理财、支出、收入、代付、加仓、提现和固定资产。
- “借款”：维护发生日期、金额、是否还清和还清日期。
- “规则”：维护动态分类，以及交易对方和商品组合匹配规则。

正向增长和收入显示为红色，下降和支出显示为绿色。

月度分析的“分类与上月对比”把分类增减额写在分类名称旁，上月和本月实际金额
写在各自柱形右侧，不需要再对照图外标签。“异常与变化”把同一分类相对上月和
近三月均值的变化合并在一行，较长说明会在单元格内自动换行；“大额支出”只列
商品和金额。顶部“对账差额”卡片只显示差额金额，并标记为“多消费少支出”、
“少消费多支出”或“平账”。差额绝对值小于 100 元时视为平账。

## 导入账单

在“流水”的月份编辑器顶部点击“导入账单”。支持 CSV、XLSX 和 XLS，Excel
工作簿读取第一个工作表。建议先按真实账单整理列名、账单范围和明显无关记录，
再进入映射窗口：

1. 选择“增量导入（追加全部）”或“覆盖当前月份”。
2. 选择日期、商品/说明、金额和收支方向对应的原始列；交易对方可选。
3. 把原始收支值逐一映射为支出、收入、代付、加仓、提现或忽略。
4. 可选映射分类和交易状态；选择状态列后，界面列出文件中的真实状态值，必须
   主动勾选允许导入的状态。
5. 生成预览，确认接受、跨月、状态过滤、忽略和无效行数量。
6. 应用到草稿，最后点击“保存月份”才写入数据库。

增量导入不执行去重。重复选择同一个文件或导入范围重叠的多份账单，会再次追加
所有有效记录；账单范围由用户自行控制。覆盖模式只替换流水草稿，不影响现金、
理财和固定资产。

同一种表头的列映射、收支值映射和状态过滤会被记住；下次自动预填，但仍显示
预览供确认。原始账单内容不会保存到插件设置。

现有 3–5 列简化格式继续作为内置映射模板：

| 表头 | 是否必需 | 说明 |
| --- | --- | --- |
| `商品` | 必需 | 流水说明，不能为空 |
| `交易对方` | 可选 | 商户、收款方或付款方，可与商品共同用于规则匹配 |
| `收支` | 必需 | 只能是 `支出`、`收入`、`代付`、`加仓`、`提现` |
| `金额` | 必需 | 数字；允许千分位逗号和 `¥`，程序按绝对值读取 |
| `日期` | 可选 | 建议使用 `YYYY-MM-DD`；缺少时预览默认使用当前月份 1 日 |
| `分类` | 可选 | 使用现有分类名称精确匹配；匹配不到时保存前质检会提示 |

最小三列表头：

```csv
商品,收支,金额
午餐,支出,35.5
工资,收入,"10,000"
```

带日期和分类的五列示例：

```csv
商品,收支,金额,日期,分类
午餐,支出,35.5,2026-07-02,餐饮基础
工资,收入,"10,000",2026-07-01,工资收入
```

没有日期时使用当前月份 1 日。导入始终逐项保留，不按商品合并。备份内部文件
不应作为普通月度账单导入。

流水区域可以在“逐项”和“按商品汇总”之间切换。逐项表按流水类型分别编号并
完整展开，不限制表内最大高度。汇总只影响查看，显示次数、总金额、日期范围和
分类冲突；展开后仍编辑原始流水。出现至少两次且尚无匹配规则的交易会进入规则
建议，用户选择分类后可立即创建规则并应用到当前草稿。

## 备份与恢复

插件不执行自动备份。

- “立即备份”先选择目录，再生成一个完整 ZIP。
- 恢复时选择 AssetTrack ZIP 或 SQLite 数据库文件。
- 恢复候选通过 Finder 选择，不需要手工输入路径；选择后自动校验。
- 候选数据必须先通过完整性和内容一致性校验。
- 替换数据库前会创建当前数据安全快照。

重要修改前应手动备份，并把重要备份复制到 Vault 或仓库之外。

新数据库只创建“默认现金账户”和“默认理财账户”。恢复数据时以备份中的账户
定义为准；已有账户不会被自动删除或停用。

## 安装环境

当前插件包含 React/Recharts 和 TypeScript `node:sqlite` 数据层，运行时不要求
用户安装 Node、Python、uv 或虚拟环境，也不区分 CPU 架构。需要 Obsidian
1.9.10 或更高版本及对应的新版桌面安装器；旧安装器缺少 SQLite API 时，插件会在
用户初始化或打开面板时提示升级，不会修改数据库。
