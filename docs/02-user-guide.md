# 02 用户指南

## 首次使用

1. 安装完整 `asset-track/` 插件目录并在 Obsidian 中启用。当前版本不能只复制
   `main.js`；完整安装命令见 [发行说明](07-release.md)。
2. 打开“设置 → Asset Track”。
3. 在“Asset_Track 根目录”中输入关键词，从 Vault 文件夹联想列表选择已有目录；
   也可以使用推荐的 `Asset_Track` 新目录。
4. 点击“使用并初始化”。数据库固定创建或读取于
   `<根目录>/data/accounting_system.db`。
5. 完成前，Ribbon 和“打开编辑器”只会引导回设置，不会创建数据库。

## 日常使用

- “分析”：Home、年度、月度实时图表。
- “流水”：现金、理财、支出、收入、代付、加仓、提现和固定资产。
- “借款”：维护发生日期、金额、是否还清和还清日期。
- “规则”：维护动态分类和商品匹配规则。

正向增长和收入显示为红色，下降和支出显示为绿色。

## 导入 CSV

在“流水”的月份编辑器顶部点击“导入 CSV”按钮。文件选择器本身是隐藏的，
可见入口是普通 Obsidian 主操作按钮。选择文件后会打开映射窗口：

1. 选择“增量导入（追加全部）”或“覆盖当前月份”。
2. 选择日期、商品/说明、金额和收支方向对应的原始列。
3. 把原始收支值逐一映射为支出、收入、代付、加仓、提现或忽略。
4. 可选映射分类和交易状态；映射状态后可选择允许导入的状态。
5. 生成预览，确认接受、跨月、状态过滤、忽略和无效行数量。
6. 应用到草稿，最后点击“保存月份”才写入数据库。

增量导入不执行去重。重复选择同一个文件或导入范围重叠的多份账单，会再次追加
所有有效记录；账单范围由用户自行控制。覆盖模式只替换流水草稿，不影响现金、
理财和固定资产。

同一种表头的列映射、收支值映射和状态过滤会被记住；下次自动预填，但仍显示
预览供确认。原始 CSV 内容不会保存到插件设置。

现有 3–5 列简化格式继续作为内置映射模板：

| 表头 | 是否必需 | 说明 |
| --- | --- | --- |
| `商品` | 必需 | 流水说明，不能为空 |
| `收支` | 必需 | 只能是 `支出`、`收入`、`代付`、`加仓`、`提现` |
| `金额` | 必需 | 数字；允许千分位逗号和 `¥`，程序按绝对值读取 |
| `日期` | 可选 | 建议使用 `YYYY-MM-DD`；缺少时预览默认使用当前月份 1 日 |
| `分类` | 可选 | 使用现有分类名称精确匹配；匹配不到时保存前质检会提示 |

最小三列表头：

```csv
商品,收支,金额
午餐,支出,35.5
工资,收入,"10,000"
```

带日期和分类的五列示例：

```csv
商品,收支,金额,日期,分类
午餐,支出,35.5,2026-07-02,餐饮基础
工资,收入,"10,000",2026-07-01,工资收入
```

没有日期时使用当前月份 1 日。导入始终逐项保留，不按商品合并。备份生成的
`transactions_backup.csv` 等完整备份 CSV 是 schema 8 的恢复材料，不应作为
普通月度账单导入。

流水区域可以在“逐项”和“按商品汇总”之间切换。汇总只影响查看，显示次数、
总金额、日期范围和分类冲突；展开后仍编辑原始流水。出现至少两次且尚无规则的
商品会进入规则建议，用户选择分类后可立即创建规则并应用到当前草稿。

## 备份与恢复

插件不执行自动备份。

- “立即备份”先打开 Finder 选择目录，再生成单个格式 2 ZIP。
- 恢复支持格式 2 目录、ZIP 或 schema 8 SQLite。
- 恢复候选通过 Finder 选择，不需要手工输入路径；选择后自动校验。
- 候选数据必须先通过 hash、表、行数、schema 和 `integrity_check`。
- 替换数据库前会创建当前数据安全快照。

重要修改前应手动备份，并把重要备份复制到 Vault 或仓库之外。

新数据库只创建“默认现金账户”和“默认理财账户”。恢复数据时以备份中的账户
定义为准；已有账户不会被自动删除或停用。

## 安装环境

当前完整插件包含 React/Recharts 和 PyInstaller Python sidecar，运行时不要求
用户安装 Node、Python、uv 或虚拟环境。当前构建按 CPU 架构生成；Apple
Silicon 和 Intel Mac 需要各自匹配的完整安装目录。
