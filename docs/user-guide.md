# 用户指南

## 首次使用

1. 安装完整 `asset-track/` 插件目录并在 Obsidian 中启用。当前版本不能只复制
   `main.js`；完整安装命令见 [发行说明](release.md)。
2. 打开“设置 → Asset Track”。
3. 在“Asset_Track 根目录”中输入关键词，从 Vault 文件夹联想列表选择已有目录；
   也可以使用推荐的 `Asset_Track` 新目录。
4. 点击“使用并初始化”。数据库固定创建或读取于
   `<根目录>/data/accounting_system.db`。
5. 完成前，Ribbon 和“打开编辑器”只会引导回设置，不会创建数据库。

## 日常使用

- “分析”：Home、年度、月度实时图表。
- “流水”：现金、理财、支出、收入、代付、加仓、提现和固定资产。
- “借款”：维护发生日期、金额、是否还清和还清日期。
- “规则”：维护动态分类和商品匹配规则。

正向增长和收入显示为红色，下降和支出显示为绿色。

## 导入 CSV

在“流水”的月份编辑器顶部点击“导入 CSV”按钮。文件选择器本身是隐藏的，
可见入口是普通 Obsidian 主操作按钮。导入只把结果放入当前草稿，不会立即写入
数据库；确认“追加”或“替换”后，还要点击“保存月份”。

导入格式不是固定四列，而是 3–5 列：

| 表头 | 是否必需 | 说明 |
| --- | --- | --- |
| `商品` | 必需 | 流水说明，不能为空 |
| `收支` | 必需 | 只能是 `支出`、`收入`、`代付`、`加仓`、`提现` |
| `金额` | 必需 | 数字；允许千分位逗号和 `¥`，程序按绝对值读取 |
| `日期` | 可选 | 建议使用 `YYYY-MM-DD`；缺少时预览默认使用当前月份 1 日 |
| `分类` | 可选 | 使用现有分类名称精确匹配；匹配不到时保存前质检会提示 |

最小三列表头：

```csv
商品,收支,金额
午餐,支出,35.5
工资,收入,"10,000"
```

带日期和分类的五列示例：

```csv
商品,收支,金额,日期,分类
午餐,支出,35.5,2026-07-02,餐饮基础
工资,收入,"10,000",2026-07-01,工资收入
```

没有 `日期` 和 `分类` 时，相同 `商品 + 收支` 的行会先合并金额；只要提供任一
可选列，就按原行保留。备份生成的 `transactions_backup.csv` 等完整备份 CSV
是 schema 8 的恢复材料，不是这个导入入口所需的简化流水 CSV。

## 备份与恢复

插件不执行自动备份。

- “立即备份”生成一致性 SQLite、9 张 CSV 和格式 2 manifest。
- 恢复支持格式 2 目录、ZIP 或 schema 8 SQLite。
- 候选数据必须先通过 hash、表、行数、schema 和 `integrity_check`。
- 替换数据库前会创建当前数据安全快照。

重要修改前应手动备份，并把重要备份复制到 Vault 或仓库之外。

## 安装环境

当前完整插件包含 React/Recharts 和 PyInstaller Python sidecar，运行时不要求
用户安装 Node、Python、uv 或虚拟环境。当前构建按 CPU 架构生成；Apple
Silicon 和 Intel Mac 需要各自匹配的完整安装目录。
