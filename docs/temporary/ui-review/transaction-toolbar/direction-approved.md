# 方向依据

用户于 2026-11-03 要求先做一版形象验证。

本轮迭代沿用此前已确认的 Asset Track 窗口与浅色界面方向，按用户给出的三分区结构制作一版可点击稿。
上方导入账单所在层沿用现有层级，仅为场景展示。

用户原话为“左边这几个是切换视图，右边有两层核心功能：编辑、分类。分类中有三个：规则分类、AI分类、修改分类；编辑中也设计三个：编辑信息、编辑标签、撤回”。

全选拟放表格第一列表头，撤回放编辑组第三位。分类与编辑两组各三个等宽按钮，与左侧视图按钮底边对齐。
本轮展示编辑信息、编辑标签两个同样式弹窗，等待用户视觉审查。

用户随后确认“这个形式不错，我们就这样修改”，并要求移除导入／手工标记，保留行内标签编辑，全选与行号排序使用独立区域。已据此进入 v2.3.3 实装。
