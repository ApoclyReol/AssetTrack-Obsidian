# 易用性优化人工测试清单

> 适用版本：当前工作区构建产物。请先执行 `npm run build`，再将 `build/` 下的三个文件加载到 Obsidian 测试环境。
>
> 记录方式：每项完成后在“结果”列填写“通过 / 失败”，并补充截图、文件样本、月份和复现步骤。C-03 是本轮明确暂缓的项目，不需要按“通过”验收。

## 0. 测试准备

| 编号 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- |

## 1. 导入账单流程

### 1.1 入口、文件结构和表头

| 编号 | 操作 | 预期 | 结果 |
| --- | --- | --- | --- |
| I-01 | 从月度页面点击“导入账单” | 入口提示能说明支持 CSV/XLSX/XLS、需要确认字段和收支映射，且不会暗示会立即写库 | [ ] |
| I-02 | 选择普通 CSV | 弹窗先进入第 1 页“确认文件结构”，显示文件格式、编码、分隔符、数据行数、识别列数和目标月份；此页不显示字段映射 | [ ] |
| I-03 | 选择 P-03 的带说明段落账单 | 系统提示表头需要确认；能看到候选表头、原始行号、原始内容和识别结果 | [ ] |
| I-04 | 在表头候选中点击第 8 行“使用此行” | 字段映射按第 8 行重建；说明段落不被当成流水；表头状态变为已确认/正常 | [ ] |
| I-05 | 在“表头行号”输入 1、8、超出范围、小数和空值后确认 | 合法行号可重新读取；非法值显示明确范围和下一步；不会静默使用错误行 | [ ] |
| I-06 | 选择一个没有可信表头的文件 | 显示“请选择包含日期、金额、商品或收支列名的行”等可操作提示；仍可输入行号尝试读取 | [ ] |
| I-07 | 选择含多张表的 XLSX/XLS | 显示工作表列表、每张表行数和表头识别结果；不默认让用户猜第一张表就是账单 | [ ] |
| I-08 | 在多工作表文件中切换“说明”与“账单明细” | 切换后重新识别行和字段；最终预览只来自所选工作表 | [ ] |
| I-08a | 在表头确认完成后点击“下一步：确认映射” | 顶部第 1 步变为完成、第 2 步高亮；第 2 页只显示导入方式、字段、收支和状态选择 | [ ] |
| I-08b | 在第 2 页点击“上一步：文件读取” | 返回第 1 页；此前已确认的工作表、表头行和映射状态保留 | [ ] |
| I-08c | 在第 2 页完成映射后点击“生成预览” | 进入第 3 页；顶部第 2 步完成、第 3 步高亮；第 3 页显示接受/过滤/异常结果和完成按钮 | [ ] |
| I-09 | 在当前弹窗点击关闭、按 Escape、点击遮罩空白处 | 弹窗关闭；未确认或未应用的内容不进入草稿 | [ ] |
