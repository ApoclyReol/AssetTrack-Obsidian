## 二、D-01 用户指定的工具栏结构

上方导入账单所在层沿用现有结构。下方一行分为视图、分类、编辑三个区，每区三个按钮，组内等宽、按钮等高并对齐底边。

| 分区 | 按钮 |
| --- | --- |
| 左侧视图 | 逐项、商品汇总、交易对手汇总 |
| 右侧分类 | 规则分类、AI 分类、修改分类 |
| 右侧编辑 | 编辑信息、编辑标签、撤回 |

编辑信息与编辑标签各自打开一个窗口，使用一致的布局与操作位置。
编辑信息合并商品、交易对手两个字段，独立填写，留空保留原值，显式勾选清空。
编辑标签集中添加与移除两种模式，支持多选，确认后进入当前草稿。

### 全选与撤回的拟定位置

- 全选位于表格第一列表头，选择数量和取消选择放在表格上方。只选择当前视图对应的流水，部分选中显示半选。
- 汇总视图选择组内全部成员，数量使用逐笔流水数。切换视图保留同一批流水的选择。
- 撤回固定在编辑组第三位。撤回对象始终为最近一次草稿操作，与当前选择无关，悬停说明具体动作。
- 无可撤回操作时按钮禁用，位置保留。沿用现有最多十步和保存后清空的口径。
- 窄窗口按完整分组换行，保留分类、编辑组各三个按钮的关系。

### 已采用的操作范围

采用“有选择时分类处理选中流水、无选择时规则分类处理本月全部”的范围。
AI 分类、修改分类与两种编辑在没有选择时禁用。范围说明就近显示于分区标题右侧。
该范围随已确认的工具栏实装，具体变更先进入当前草稿。

可点击稿见 [流水工具栏与编辑窗口](ui-review/transaction-toolbar/index.html)，示例数据仅保存在当前页面。
