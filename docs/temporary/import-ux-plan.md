## 本轮范围

本轮已从单一导入弹窗扩展到此前清单中已经计划的导入、流水、规则、月度工作台、分析与配置体验。导入弹窗现在保留顶部四步指示器，但将内容拆成“文件结构 / 字段与筛选 / 预览”三个子页面。没有修改数据库结构、财务计算口径、自动保存、自动去重或自动写库流程。

统一保留以下安全边界：

- 导入仍然是“选择账单 → 确认结构和映射 → 预览 → 加入当前草稿 → 用户保存”。
- 接受流水先加入当前草稿，再单独保存字段映射；映射保存失败不撤回已加入的草稿，只显示明确提醒。
- 规则、批量编辑、类型转换和 AI 建议仍然是“预览 → 确认 → 进入草稿 → 保存”。
- 追加模式不自动去重；替换模式只替换当前流水草稿。
- 有质检错误时不会调用保存 Service；财务计算继续使用现有口径。

## 本轮针对截图的具体修复

- 导入字段映射在较窄弹窗中改为纵向排列，字段名和控件不再共用会截断文字的单行布局。
- 收支映射卡片取消白色内容块，改为透明卡片和主题边框，原始值、数量、目标映射保持同一行层级。
- 必填区、可选区下方的“示例：……”小字已从界面移除，保留字段用途、空值数量和悬停提示所需的信息。
- 导入方式、必填字段、可选字段、收支映射、导入状态统一使用同一套 fieldset 标题层级和主题颜色规则。
- 导入弹窗保留顶部四步过程展示，内容分为三个子页面：文件读取页包含工作表和表头选择，确认映射页包含字段/收支/状态，预览页提供完成并加入草稿。
- 接受行成功加入草稿后才保存映射；映射保存失败显示“流水已加入，但映射未保存”，不回滚草稿。
- 流水逐项视图默认突出日期、商品、金额；工具栏只保留视图用途的灰色说明，不再增加显示/隐藏分类和交易对手按钮；有这两类问题时相关字段会自动显示，避免问题被隐藏。
- 流水页不再堆叠问题汇总框，只保留一行红色问题提醒；具体原因通过行号旁的 `!` / `?` 标记查看，移除行号下重复的文字说明。汇总视图展开的子表使用接近母表的主题背景，并通过轻微层级标记区分；子表列宽按母表“类型 / 商品或对手 / 次数 / 金额 / 分类 / 操作”列映射，内容区合并母表的商品、次数和金额三列。
- 月度分析保留对账差额指标，但不再额外堆叠完整解释面板；流水页差额旁的 `?` 提供平账、正差额、负差额和无连续基准的说明。
