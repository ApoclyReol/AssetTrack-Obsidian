# Asset Track

[English](README.md) | 简体中文

> **每月导入一次账单，就能知道钱去了哪里、资产发生了什么变化，以及这份记录是否完整。**

Asset Track 是一款面向月度结算的本地私有个人财务工具。它把支付平台导出的账单
整理成一套统一的财务记录，帮助你查看消费、资产、借款、理财和数据缺口。

你不需要在每次消费后马上记账。Asset Track 的工作方式是：每月集中导入已经存在的
账单，处理少量需要你判断的问题，检查结果，然后结束本月整理。

## 为什么使用 Asset Track

- **每月一次**：用集中整理代替持续手工记录。
- **统一记录**：不同账单格式最终进入同一个本地 SQLite 事实源。
- **可以验证**：通过流水和资产变化发现遗漏或不一致。
- **完全私有**：无需账户、不联网、无遥测、不依赖云端分类。

核心原则很简单：系统负责重复整理，最终判断始终交给你。

## 它是怎么工作的

```text
导出账单
    ↓
导入并确认字段
    ↓
处理异常和分类
    ↓
补充月末资产、借款和理财
    ↓
完成对账并查看结果
```

## 适合哪些人

如果你符合下面几项，Asset Track 会比较适合你：

- 主要使用微信、支付宝、银行卡等电子支付；
- 不想养成每天记账的习惯；
- 愿意每月集中整理一次账单；
- 重视财务数据的私有和本地所有权；
- 不只想看消费图表，也想理解资产变化。

## 它能做什么

- 导入 CSV、XLSX 和 XLS 账单，并记住常用字段映射；
- 管理月度流水、账户、借款、理财和固定资产；
- 为加仓、提现选择具体理财账户，并按账户查看月度理财状态；
- 用分类以及商品、交易对手、组合规则减少重复整理；
- 通过出账、入账、理财 Tab 和逐项/商品/交易对手汇总视图整理流水；
- 批量修改在同一窗口预览并确认，收入/代付转换先预览，并保留本地审计记录；
- 可选的 AI 分类只生成建议，不会未经确认写入；
- 检查冲突、未分类和数据缺口；
- 查看月度、年度消费和资产分析；
- 通过流水与资产变化完成对账；
- 在本地备份、恢复和迁移数据。

## 开始使用

1. 打开“设置 → 第三方插件 → 浏览”，搜索并安装 **Asset Track**。
2. 打开“设置 → Asset Track”，在当前 Vault 内选择一个专用数据目录。
3. 空目录选择“创建新数据库”，已有数据库则选择“载入数据库”。
4. 从命令面板或功能区打开编辑器。
5. 导入本月账单，处理异常，补充月末资产，然后保存本月。

如果社区目录不可用，只从同一个 GitHub Release 下载 `main.js`、`manifest.json` 和
`styles.css`，放入 `<Vault>/.obsidian/plugins/asset-track/`。不要安装 GitHub
自动生成的源码压缩包。

## 数据与隐私

你的财务数据保存在当前 Vault 内由你选择的目录中。Asset Track 不要求注册账户，
不会追踪财务行为。除非你主动配置并使用可选的 AI 分类，否则不会连接服务器；启用后，
只会把选中的流水和分类所需定义发送到你配置的 API。备份和恢复由你主动发起；禁用或卸载
插件不会删除数据库和备份。

## 兼容性

- 仅支持桌面版 Obsidian：macOS、Windows 和 Linux。
- 1.7.1 要求 Obsidian 1.13.0 或更高版本。安装或更新前，请先升级到最新可用的
  1.13.x 桌面版。
- 不需要 Python、单独安装的 Node.js 或 sidecar。
